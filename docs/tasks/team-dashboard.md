# team-dashboard

## 目标与验收条件
- 通过服务器 IP:端口查看 PostgreSQL 中的用户、团队、成员关系、设备与项目。
- 按维护者选择提供访问保护；页面只读，支持搜索和分页，空库不填充假数据。

## 关键决定
- 用户明确选择先保护再展示数据；不采用无认证公开目录。
- 8 天自签名测试证书；首次浏览器信任需用户确认。以后替换受信任证书。
- 临时查看账号可查看全部目录，不能视为最终团队权限体系。

## 失败尝试
- 无认证公网目录部署被自动审批拒绝；用户选择访问保护，改用 HTTPS 和随机查看密码。
- 临时测试库首次没有匹配 SCRAM 规则，加入只针对临时库的规则后验证，随后恢复原配置。
- 唯一性测试夹具触发邮箱前缀约束，修正合成邮箱后通过；生产约束未放宽。
